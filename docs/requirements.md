# RimChecker 需求说明

## 项目目标与目标用户

面向需要排查 RimWorld（环世界）运行问题的玩家，逐步提供日志整理、候选异常提取和诊断报告能力。未来可以帮助玩家查看可能相关的 Mod，并选择自己的 AI 服务辅助分析；结论需要有日志依据，不能仅凭关键字声称找到了根因。

## 第一阶段 MVP 范围

- 提供 Go 命令行程序，使用 `-log` 接收一个明确的普通日志文件路径，支持带空格路径和 `-help`。
- 使用标准库逐行流式读取，支持 LF、CRLF、空文件、末尾无换行符以及超过 64 KiB 的单行。
- 返回包含文件路径、打开时文件大小（字节）、总行数、候选异常行数、各类型数量和候选详情的结构体。
- 按忽略大小写的子串识别 `Exception`、`Error`、`Warning`，同一行按此前顺序归类一次，避免重复计数。
- 记录从 1 开始的行号、候选类型和最多 200 个 Unicode 码点的摘要，截断时追加 `…`。CLI 最多展示前 10 条，统计覆盖整个文件。
- 对参数错误、路径不存在、不可读文件、非普通文件和读取中途失败返回清晰错误，不因普通输入错误 panic。
- 仅保存候选行元数据和摘要，不保存整个日志。读取时仍需容纳完整单行，候选详情列表随候选数量增长。

本阶段规则是产品自定义的初步筛选规则，不是已验证的 RimWorld 专用解析规则。所有计数均称为“候选异常行数”，不称为已确认异常数量。三类数量相加等于候选异常行数。

## 第一阶段当时不实现（历史范围）

- 自动发现日志路径、监控游戏目录、增量扫描。
- 多行异常或调用堆栈解析、异常去重、Mod 定位与根因推断。
- AI API 接入，模型、API 地址、Key、提示词配置和持久化。
- Wails、Vue 3、桌面 GUI 和安装包。
- 编码自动检测、非 UTF-8 转码、压缩文件、标准输入或远程日志。

第一阶段不扫描真实用户隐私目录、不上传日志、不自动推送 GitHub。后续授权上传规则见 Sprint 03 范围。

## 基本验收标准

1. `go test ./...`、`go vet ./...`、`go build ./cmd/rimchecker` 全部成功。
2. `go run ./cmd/rimchecker -log "./testdata/fixtures/sample.log"` 输出 11 行、6 条候选异常行，Exception/Error/Warning 各 2 条；大小等于文件实际字节数。
3. `-help` 正常展示用法，缺失参数及不存在路径展示错误并返回非零状态；含空格路径可正常扫描。
4. 测试覆盖正常读取、空文件、路径不存在、多行候选识别、CRLF、超过 64 KiB 的单行与大小写差异。
5. 核心扫描模块不依赖 CLI、GUI、AI 或第三方库，结果可供未来上层模块复用。
6. 示例和自动化测试使用人工合成日志，文档明确声明其不是真实 RimWorld 日志。

不可读文件测试在权限机制允许时执行；若宿主仍允许读取则明确跳过，不能据此声称已验证该平台的权限拒绝行为。扫描中途读取错误通过可控的失败 Reader 验证。

## Sprint 02 范围

保留上述扫描 API、默认 CLI 行为与原有测试，新增独立 `internal/logparse`，不修改 `internal/logscan`。

- 通过有限的记录头、堆栈和 Verse 日志调用规则区分 Legacy / Waylith / Unknown，不把格式识别当成游戏版本识别。仓库只包含合成样本，不声称覆盖全部真实格式。
- 提取完整事件：等级、标题、完整消息、原文、堆栈、起止行号、可用的时间戳和来源。全部原文可由事件顺序拼接恢复，INFO 与 Unknown 也必须保留。
- 明确记录头开始新事件，堆栈中的 Error 不作为记录头；堆栈之后的下一条无标记消息另起记录。边界有歧义时保留原文并标记，不将下一条明确记录的堆栈合并到前一条。
- 只对 ERROR / WARNING / FATAL 事件去重，比较等级、来源、完整消息和堆栈，忽略记录时间戳和行号。保留正文数字、路径、Mod 标识和堆栈细节；不同堆栈不合并。
- 保留首次完整代表事件、发生次数、首次和末次事件各自的起止行号。未去重记录仍在 `events` 中。
- 增加 `-mode scan|parse`，默认 scan；增加 `-format text|json`，默认 text。JSON 标准输出不得混入普通提示，参数或读取错误只输出到标准错误流。

当前解析结果保留全部日志原文，内存随文件大小增长；不采用第一阶段的短摘要代替完整事件。

## Sprint 02 当时不实现（历史范围）

AI API、GUI、Mod 根因判断、自动修复、游戏进程监控、网络上传、自动日志搜索、编码自动转码与复杂插件系统均不实现。

## Sprint 02 验收

1. 原有测试与新增解析/去重/CLI 测试通过；`go test ./...`、`go vet ./...`、`go build ./cmd/rimchecker` 成功。
2. 第一阶段示例同时可用于默认扫描、`-mode parse` 及 `-mode parse -format json`，默认扫描统计保持不变。
3. 合成 Legacy 样本 22 行：4 次诊断、3 组，其中重复异常首次 8–11 行、末次 15–18 行；合成 Waylith 样本 19 行：5 次诊断、4 组。
4. 覆盖多行异常、带时间戳 ERROR、重复 100 次、同名不同堆栈、INFO 中的 Exception、连续异常、空文件、不完整堆栈、CRLF/LF、中文、行号和合法 JSON。
5. 格式的具体支持范围、观察来源和已知限制记录在 `docs/log-formats.md`；使用合成数据的事实明确可见。

## Sprint 03：可配置 AI 诊断

- 保留 scan/parse API、默认行为和所有现有测试，不修改日志解析算法。
- 使用标准库 net/http 实现 OpenAI-compatible 非流式 Chat Completions；用户选择 Base URL、模型、密钥、超时及独立 Markdown 系统提示词，无绑定模型和可选采样参数。
- JSON 配置不接受 API Key，从 RIMCHECKER_API_KEY 环境变量读取。配置严格验证，提示词提供文件读取和保存接口供未来 GUI 使用。
- 输入仅基于结构化去重结果，提供格式、错误/警告统计、组、消息、堆栈、次数和首末行号；不提供整个日志和 RawText。
- 可配置组数/字符限制，先清理常见敏感信息再裁剪，裁剪必须显式标记。日志作为不可信数据，不进入配置或 system 角色。
- AI 必须主动触发：`-mode ai -preview` 只预览；真实发送要求 `-allow-upload` 和有效配置/提示词/密钥。Provider 层也必须验证上传授权。两参数同时指定时只预览。
- context 支持取消和超时；HTTP client 可注入。处理 401、429、5xx、网络失败、无效 JSON 和空文本，响应读取上限 1 MiB。不自动重试、不跟随重定向、不默认记录原文/密钥/完整请求。
- 默认提示词要求中文、区分事实和推测、基于证据说明可能相关 Mod、按优先级给出排查建议、明确缺失信息、不编造内容、不建议未经确认删除存档或修改重要文件。

Sprint 03 当时不实现 GUI、多轮对话、自动操作 Mod、文件修复/删除/重排、进程监控、模型能力探测与流式输出。AI 不是确定性根因引擎，清理不是全面的隐私保证。

## Sprint 04：Windows 最小桌面应用

定位限定为本地日志分析和用户配置的 AI 解释。永久排除 Mod 下载/管理/排序/修复、修改游戏或存档、账号系统、云数据库、社区、插件系统、多轮聊天与自动更新。

- Wails v3.0.0 Service + 自动生成 TypeScript bindings；Vue 3 / Vite / CSS 实现简体中文深色单窗口，无重型 UI 框架。
- 原生文件选择，只解析显式选择的日志；统计来自现有 Go 解析器，展示分组、等级筛选、详情、完整堆栈与复制。不暴露任意路径读写接口。
- API 非敏感配置和提示词保存到系统用户配置目录；密钥仅在本次运行的内存中，GUI 不使用环境密钥。取消草稿与恢复默认均须避免暗中覆盖已保存内容。
- AI 明确预览后确认一次；Go 保存目标模型/提示词/输入快照和一次性令牌，状态改变失效。发送只使用保存的快照，必须支持取消。复用 Sprint 03 客户端，不新增网络实现。
- 安全显示 Markdown：HTML 禁用，DOMPurify 白名单禁止脚本、嵌入内容和外链。普通输入错误返回中文提示，异步 bindings 不阻塞前端事件循环。
- 验收：全部 Go 测试、vet、CLI build、前端类型检查/生产构建、Wails Windows EXE build；Service Mock 测试覆盖解析一致性、持久化、提示词、授权、取消、预览失效及密钥不落盘。实际 GUI 交互与仅测试的部分分别报告。

当前便携版目标 Windows amd64，需要 WebView2。安装包签名、干净机器验证、真实脱敏日志与极大日志性能验证留待 v1.0 发布前完成。

### Sprint 03 验收

`go test ./...`、`go vet ./...`、`go build ./cmd/rimchecker` 成功；示例 AI 预览可运行且不访问网络。测试仅使用回环 Mock API 和合成密钥，覆盖正常响应、Header、自定义模型/地址/提示词、401/429/500、超时/取消/断线、无效/空/超大响应、未授权和预览零请求、输入裁剪、清理以及旧模式兼容。

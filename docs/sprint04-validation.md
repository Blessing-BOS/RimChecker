# Sprint 04 验证记录

验证日期：2026-10-30，Windows 11 amd64。Go 1.27.2、Node 26.4.0、npm 11.17.0、WebView2 156.0.4314.56、Wails v3.0.0。Wails doctor 报告可进行桌面开发。缺少 NSIS/MSIX/签名工具，本阶段只构建便携 EXE。

## 自动化覆盖

- 原有 CLI、扫描、解析与 AI Mock 测试全部保留。
- Service 结果与直接调用 logparse.Parse（CLI 同一入口）对照，格式、总行数、分组和次数一致。
- 设置重载、提示词读取/保存/恢复、非法提示词拒绝、重建 Service 后无密钥。
- 未确认和仅预览不请求网络；Mock 请求成功；context 取消返回中文取消信息。
- 返回预览 DTO 被调用方修改、磁盘日志在预览后变化时，实际发送仍与原始快照严格一致。
- 设置、密钥、提示词、文件选择、重新解析和丢弃预览均使旧令牌失效；消费过的令牌不能再使用。
- 空文件、缺失路径、未选择日志分别处理；检查配置目录所有持久化文件不含合成 API Key。
- 前端类型检查与 Vite 生产构建；Wails 自动生成 1 个 Service、12 个方法的 bindings。

## 已做真实窗口交互

使用隔离 APPDATA 指向项目 `.tools/gui-profile`，没有修改日常用户配置。

1. 启动实际 Windows 原生 EXE，确认 WebView2 窗口展示中文界面。
2. 通过系统文件选择对话框选择项目内 legacy-synthetic.log；没有寻找或扫描真实玩家日志。
3. 点击解析，界面显示 22 行、Error 3 次、Warning 1 次、去重 3 组。
4. 点击另一条异常，确认完整消息、首末行号和堆栈相应切换。
5. 在设置界面填写回环 Mock 地址、合成模型与合成 Key 并保存；重读磁盘 settings.json，仅包含非敏感字段。
6. 编辑并保存自定义提示词，在发送预览中确认使用了该文本。
7. 显示发送预览，确认目标端点、模型、system messages 和日志 JSON 都可检查。
8. 明确确认后向回环 Mock 服务发送合成数据，界面展示实际返回的中文 Markdown 标题和列表。
9. Mock 响应中的 script 标签作为可见普通文本显示，没有脚本弹窗。

取消请求已通过 Service 的活动 HTTP Mock 测试，未完成原生窗口中“慢请求→点击取消”的手工闭环。恢复默认、未保存草稿询问、复制、所有窗口缩放/DPI 和分页边界尚未逐项人工回归，不能将构建成功视为所有交互已验证。

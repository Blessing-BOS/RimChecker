# RimChecker v0.9.0-beta

Release notes for the first public beta. These materials are a draft; no GitHub Release has been created.

## Features

- Local parsing of RimWorld Legacy / Waylith-style logs, including multiline messages, stacks, and line numbers.
- Error and warning classification, grouping of repeated messages with matching stacks, counts, and first/last locations.
- A dark Simplified Chinese Windows interface with severity filters, stack copying, and a collapsible AI panel.
- Configurable Chat Completions-compatible API, model, timeout, and diagnostic prompt.
- Sanitized, bounded AI input with explicit preview and upload confirmation, plus request cancellation.
- Existing scan / parse / ai command-line modes and JSON output.

## Platform and Installation

Windows x64, currently verified on Windows 11 x64. WebView2 Runtime must be installed separately. A clean Windows 10 installation has not been verified.

Once published, download RimChecker-v0.9.0-beta-win-x64.zip and its SHA256 file from this repository's Releases page. Verify the checksum, extract the ZIP, and run RimChecker.exe. Go, Node.js, and a development server are not required. This portable package is unsigned and has no installer or automatic updater.

## Usage

Select a log → start parsing → review grouped errors and stacks. Common Windows log directory:

~~~text
%USERPROFILE%\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios
~~~

RimWorld 1.7 logs may also be in the Logs subdirectory. The picker allows browsing into subdirectories or any other location. File selection does not start parsing automatically.

## AI API Notes

Supply your own compatible API service and credential; provider charges may apply. The API Key is held only in memory for the current desktop session. Non-sensitive settings and prompts are stored in the user configuration directory.

The preview shows the destination, model, prompts, and sanitized log input. Upload happens only after explicit confirmation; full raw logs are not sent. Filtering cannot catch every private detail, so inspect the preview yourself. Cancellation does not guarantee the provider stops billing. Requests are not retried automatically.

AI provides suggestions to verify. It cannot operate on files, repair Mods, or reorder them.

## Known Limitations

- Format compatibility is partial. Some native crashes, nested exceptions, and third-party wrappers are not fully recognized. Format labels do not prove a game version.
- UTF-8 input is expected. Encoding conversion and stack-reference expansion are not supported.
- Large logs require more memory; parsing cannot currently be canceled.
- The desktop UI is Simplified Chinese only; no other desktop platforms are packaged.
- AI may misdiagnose issues. Streaming and multiround conversations are not supported.
- Clean-system checks and all DPI / multimonitor combinations have not been verified.
- The executable still uses the Wails template icon, with its attribution retained.

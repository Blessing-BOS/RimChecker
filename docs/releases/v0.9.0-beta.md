# RimChecker v0.9.0-beta

首个公开测试版本的发布说明。当前材料为发布草稿，尚未创建 GitHub Release。

## 主要功能

- 本地解析 RimWorld Legacy / Waylith 风格日志，提取多行消息、调用堆栈与行号。
- 区分错误和警告，合并相同消息及堆栈的重复异常，显示次数及首末位置。
- 简体中文 Windows 深色界面，支持等级筛选、堆栈复制与可折叠 AI 结果面板。
- 自定义兼容 Chat Completions 的 API、模型、超时和诊断提示词。
- AI 请求经过脱敏和裁剪，用户预览并确认后才发送，支持取消。
- 保留 scan / parse / ai 命令行模式及 JSON 输出。

## 支持平台与安装

Windows x64，当前在 Windows 11 x64 验证。需要单独安装 WebView2 Runtime；干净 Windows 10 环境尚未验证。

正式发布后从本仓库 Releases 下载 RimChecker-v0.9.0-beta-win-x64.zip 和对应的 SHA256 文件，核对校验值、解压后运行 RimChecker.exe。无需 Go、Node.js 或开发服务器。当前便携包未签名，不含安装器或自动更新。

## 使用

选择日志 → 开始解析 → 查看错误分组与堆栈。Windows 常见日志目录：

~~~text
%USERPROFILE%\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios
~~~

RimWorld 1.7 的日志也可能位于其中的 Logs 子目录。选择器允许进入子目录或切换到任意其他目录，选择文件不自动解析。

## AI API 注意事项

用户需自行提供兼容 API 与密钥，第三方服务可能收费。API Key 仅保留在本次桌面运行的内存中。非敏感配置及提示词保存在用户配置目录。

发送前会预览目标服务、模型、提示词与经清理的日志输入。只有明确确认后才上传，不发送完整原始日志。过滤不能覆盖所有隐私信息，务必自行检查。取消不保证服务商停止计费，程序不会自动重试。

AI 只能提供需要核实的分析建议，不会操作文件、修复 Mod 或调整排序。

## 已知限制

- 日志格式兼容性有限，部分原生崩溃、嵌套异常和第三方包装不被完整识别；格式标签不证明游戏版本。
- 预期 UTF-8，不自动转码或展开堆栈引用。
- 大日志解析会消耗较多内存，解析阶段暂不支持取消。
- 当前桌面界面仅简体中文；没有其他平台桌面包。
- AI 可能误判；不支持流式输出或多轮对话。
- 干净系统及所有 DPI / 多显示器组合尚未验证。
- 程序图标仍来自 Wails 模板，并已保留相关许可声明。

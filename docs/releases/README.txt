Portable Windows x64 build. Extract and run RimChecker.exe.
Microsoft Edge WebView2 Runtime is required (official link above).
Go, Node.js, source files, and a development server are not required.

The UI is Simplified Chinese. Select a log, start parsing, and select an
error to inspect its stack. Logs may also be in the Logs subdirectory.

AI diagnostics require your own compatible API, model, and API Key.
Keys are kept only in memory for the session. Non-sensitive settings and
prompts are stored in %APPDATA%\RimChecker.
Provider charges may apply. Review the full preview before confirming;
privacy filtering can miss sensitive data. Verify AI suggestions.

This unsigned beta has no installer or auto-updater. Format coverage is
partial, and large logs may use significant memory. It does not modify
Mods, game files, or saves.
